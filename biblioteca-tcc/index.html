Como funciona

Simples de usar,
fácil de contribuir

Sem login, sem instalação. Abre e usa.

01
Acesse qualquer material
Cada material é uma página HTML — funciona no celular, tablet e computador.
02
Use na supervisão
Navegue pelo índice interativo e use as seções como roteiro de discussão clínica.
03
Contribua via GitHub
Fork, crie seu material em HTML e abra um Pull Request. Toda contribuição é bem-vinda.
04
Acesso gratuito para sempre
Open source publicado via GitHub Pages. Sem barreiras de acesso.
